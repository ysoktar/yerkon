# Parça fotoğrafları

Sistem sayfasındaki iki şeridin fotoğrafları. Bir fotoğrafı buraya koyup
`src/yerkon/viewer/pages.py` içinde `FINAL_PARTS` ya da `PILOT_PARTS`
listesinde parçanın yanına dosya adını yazmak yeter; `yerkon pages` onu
`docs/photos/` altına kopyalar. WebP, 4:3, en çok 800 piksel genişlik
yeterli.
