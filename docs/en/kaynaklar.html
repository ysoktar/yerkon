What it rests on

A number comes from a datasheet, from a published measurement, or from an assumption written down. The third kind carries its own type in this project, so the ones nobody supplied can be counted.

How to reproduce it

pip install -e ".[dev]"
yerkon table          # the published numbers, about 15 min
yerkon table --fast   # about 1 min, not publishable
yerkon view           # this site and the simulator
  • The ground is baked into the package, so the table above reproduces with no network at all. The seed is fixed.

Standards and data

  • ITU-R P.526-15 §4.5.2, delta Bullington diffraction.
  • ITU-R P.452 and P.1812: how loss is built up.
  • 3GPP TR 38.901 Table 7.4.1-1: shadowing widths.
  • Copernicus DEM 30 m: ground heights.
  • OpenStreetMap and Overture: buildings and roadside furniture.
  • Semtech SX1280, EBYTE E28-2G4M27S and Qorvo DWM3000 datasheets.
  • DigiKey, LCSC and Mouser list prices, 6 September 2026.

What the repository holds

  • CONTEXT.md is the glossary: the name the code uses for each term beside the one the report uses.
  • docs/adr/ holds every decision and what it replaced.
  • docs/HANDOFF.md holds the open questions and the figures still standing in for real ones.
  • The documents are in Turkish and the code is in English.

The project

  • YERKON is an idea submitted to UDHAM's “Ulaşan ve Erişen Türkiye 2053” inter-university competition, run by the Ministry of Transport and Infrastructure, July 2026.
  • The team, at TOBB University of Economics and Technology: Mustafa Göktürk Binay, Mehmet Gönül, Yavuz Selim Oktar (group representative).
  • This repository is not the report. It is the simulation that produces the YERKON block on page 15 of it.
