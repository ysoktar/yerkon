Reproducing the table

pip install -e ".[dev]"
yerkon table          # the published numbers, ~15 min
yerkon table --fast   # for trying things, ~1 min
yerkon view           # this site and the simulation
  • The ground is baked into the package, so the table reproduces with no network at all. The seed is fixed.
  • CONTEXT.md is the glossary: the name the code uses for each term beside the one the report uses.
  • docs/adr/ holds every decision and what it replaced. docs/HANDOFF.md holds the open questions.

The project

  • YERKON is an idea submitted to UDHAM's “Ulaşan ve Erişen Türkiye 2053” inter-university competition, run by the Ministry of Transport and Infrastructure, July 2026.
