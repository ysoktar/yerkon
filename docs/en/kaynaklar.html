What it rests on

Every number here comes from one of three places: a product's datasheet, a published measurement, or an assumption written down. The third kind carries its own type in the code, so it can be counted how many numbers have no real source behind them.

Reproducing the table

pip install -e ".[dev]"
yerkon table          # the published numbers, ~15 min
yerkon table --fast   # for trying things, ~1 min
yerkon view           # this site and the simulation
  • The terrain data ships inside the package, so the table reproduces with no network at all. The random seed is fixed, so every run gives the same answer.
  • CONTEXT.md is the glossary: the name the code uses for each term beside the one the report uses.
  • docs/adr/ holds every decision and what it replaced. docs/HANDOFF.md holds the open questions.
